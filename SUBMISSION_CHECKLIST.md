# Submission checklist

- [ ] Install dependencies and run the backend.
- [ ] Configure a real local or Atlas MongoDB URI in `backend/.env`.
- [ ] Run `npm run seed` inside `backend`.
- [ ] Run the frontend and test customer and studio workflows.
- [ ] Check all 401, 403, 404 and conflict/error cases.
- [ ] Check `.env` and all real secrets are excluded from Git.
- [ ] Ensure `.env.example` files are committed.
- [ ] Update `DESIGN.md` so it accurately describes what was tested and completed.
- [ ] Add screenshots if desired (not required by the brief).
- [ ] Push to a public GitHub repository.
- [ ] Record a voice demo of at most five minutes.
- [ ] Upload the demo to Google Drive and set access to anyone with the link.
- [ ] Submit the public repository URL and demo link through the required Google Form.
